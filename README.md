# NEXUS

## AI Career Intelligence & Skill Gap Analysis System

NEXUS is a Java-based career intelligence system designed to analyze student skills, identify career and job compatibility, detect skill gaps, and generate personalized career development recommendations.

## Status

🚧 Project under development

## Technology

- Java
- Object-Oriented Programming
- Java Collections & Algorithms
- JDBC
- SQL Database
- JavaFX
- JUnit
- Maven
- Git & GitHub

## Planned Features

- Student profile management
- Skill management
- Career compatibility analysis
- Skill gap analysis
- Job matching
- Personalized recommendations
- Progress analytics
- Database integration
- Testing
